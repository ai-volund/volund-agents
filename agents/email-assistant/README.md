# Email Assistant

A specialist agent for managing email — reading, searching, drafting, and sending messages.

## Skills Used
- **email** — full email access (Gmail, Outlook, IMAP)
- **calendar** — check availability for scheduling
- **memory** — remember contacts and preferences

## Best For
- Inbox triage and summarization
- Drafting professional replies
- Email search and organization
- Scheduling-related correspondence
